# UI Inspiration — MY Journal reference

Source: user-provided UI/code reference (`Pasted text(2).txt`).

## Design direction

- Clean, modern trading operating-system aesthetic.
- Light interface with a very soft blue/gray background.
- White translucent/glass cards with subtle borders, blur, and restrained shadows.
- Inter for interface text and JetBrains Mono for trading/statistical numbers.
- Blue as the primary action/accent color.
- Green for wins/positive states and red for losses/violations.
- Compact, information-dense dashboard without feeling cluttered.
- Rounded cards and controls, generally 10–18px radius.
- Sticky top navigation with a segmented/pill navigation treatment.
- Clear separation between Home, Trading, Journal, Analytics, and Settings.
- Trading console uses compact controls, KPI cards, charts, execution table, calendar heatmap, and account widget.
- Journal uses filters plus a detailed trade table and right-side trade inspection drawer.
- Analytics emphasizes KPI cards, equity/performance charts, strategy/timeframe/regime breakdowns, and evidence-based insights.
- Settings groups account, risk/discipline, MT5 bridge, and backup controls.
- Responsive layouts that collapse cleanly on smaller screens.

## Important implementation note

This is inspiration, not a requirement to copy the reference literally. Preserve the existing application's working functionality and data. Reuse the visual language where it improves the product, while adapting the information architecture to the project's actual trading-system requirements in `PROJECT-STATE.md`.

## Visual elements worth carrying forward

1. Soft blue-gray application background.
2. White/glass content surfaces.
3. Blue primary actions and navigation state.
4. Green/red semantic performance states.
5. Monospaced financial metrics.
6. Dense but readable tables.
7. Right-side trade inspection drawer.
8. Calendar P&L heatmap.
9. Performance/discipline analytics cards and charts.
10. Minimal, professional trader-terminal feel rather than a generic SaaS template.
